How It Works · Cohort Awards

About This Leaderboard

What this project is, how the standard card works, and exactly how voting and the live results screen are meant to run.

Overview

Four Awards, One Public Vote

Every project is judged by the cohort itself, on the same information, across four categories.

Instead of separate criteria per category, every project is presented with one identical set of details. Voters read the same card for each project and decide for themselves which project deserves each award — Best ROI, Best Technical, Best Creative, and Cohort Choice.

Why this works: a single consistent format keeps the vote fair — no project is dressed up differently to chase a category — and it's far simpler to build, present, and vote on live during the ceremony.
🏆 Best ROI 🏆 Best Technical 🏆 Best Creative 🏆 Cohort Choice

A voter can give different votes to different projects across categories — e.g. Project A for ROI, Project B for Technical, Project C for Cohort Choice — all from reading the same card.

Section 02

Voting Mechanics

One card, four vote buttons, real-time tally.

RuleRecommendation
Votes per person / categoryOne vote per person per category — prevents any single voter from dominating a result.
Self-votingDecide upfront whether participants can vote for their own project, and state the rule clearly on the voting page.
Voting windowOpens once all project cards are published; closes shortly before the awards reveal to build suspense.
Project orderRandomized per voter session to avoid a "first project gets more votes" bias.
Before votingVoters are required to view every project card before their first vote is accepted.
Open decisions for you: can one voter pick the same project for more than one category, and can a category have more than one vote per voter? Both should be fixed and stated before voting opens.
Solo-participant risk: since each project is built by one individual rather than a team, Cohort Choice can drift toward "who's well-liked" rather than "best project." Keep the participant photo secondary to the project demo on the card, and frame Cohort Choice as "the project I'd most want to see become real" rather than a popularity pick.
Cohort Choice eligibility: unlike the other three awards, Cohort Choice is limited to a specific roster (managed in Admin — typically the cohort itself). The first time someone votes in that category, they pick their name from the roster; it's then remembered on their device. Best ROI, Best Technical, and Best Creative stay open to anyone.

  • Keeps the room engaged through every presentation
